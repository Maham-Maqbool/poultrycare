# PoultryCare Audio Assets

This directory contains dedicated audio recordings and stream paths for the 4 diagnostic disease classes:
1. `newcastle.mp3` : Spoken Urdu guidance for Newcastle Disease (Ranikhet)
2. `coccidiosis.mp3` : Spoken Urdu guidance for Coccidiosis (Bloody Diarrhea)
3. `salmonella.mp3` : Spoken Urdu guidance for Salmonella (Pullorum Disease)
4. `healthy.mp3` : Spoken Urdu guidance for Healthy Flock Digestion

When audio files are present, they can be streamed; in all environments, high-definition on-device speech synthesis (TTS) operates with dynamic Urdu/English vocal guidance.
