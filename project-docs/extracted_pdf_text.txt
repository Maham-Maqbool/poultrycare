Public benchmarks for this dataset report 97–99 % accuracy, but many use a random
split. In this dataset several photos of the same sample/session look almost identical,
so a random split leaks near-copies from train into test and inflates accuracy
(Chidziwisano et al. 2025 show accuracy dropping from 91 % to 69 % on data from
another country). So here we (a) find near-duplicate images, (b) keep each duplicate
group entirely inside one split, and (c) report that honest number.

Your documentation (FR-10) asks for blur, brightness variation and controlled
noise. Those are implemented below, together with flips / small rotations / zoom (a
dropping has no "up" direction).
Colour is deliberately not jittered strongly (no hue shift): colour is one of the main
visual cues of these diseases, so destroying it would hurt the model. Only mild
saturation changes are used.
Augmentation runs on the training set only; validation and test images are never
modified.

def gaussian_blur(x, sigma, k=7):
    ax = tf.range(-(k // 2), k // 2 + 1, dtype=tf.float32)
    g = tf.exp(-(ax ** 2) / (2.0 * sigma ** 2)); g = g / tf.reduce_sum(g)
    kern = tf.tile((g[:, None] * g[None, :])[:, :, None, None], [1, 1, 3, 1]
    return tf.nn.depthwise_conv2d(x, kern, [1, 1, 1, 1], "SAME")
def augment_batch(x, y):
    x = tf.cast(x, tf.float32)
    x = _flip(x, training=True); x = _rot(x, training=True)
    x = _zoom(x, training=True); x = _shift(x, training=True)
    B = tf.shape(x)[0]
    u = lambda lo, hi: tf.random.uniform([B, 1, 1, 1], lo, hi)
    coin = lambda p: tf.cast(tf.random.uniform([B, 1, 1, 1]) < p, tf.float32
    x = x * u(0.75, 1.25)                                              # bri
    m = tf.reduce_mean(x, axis=[1, 2, 3], keepdims=True)
    x = (x - m) * u(0.8, 1.2) + m                                      # con
    gray = tf.reduce_mean(x, axis=-1, keepdims=True)
    x = gray + (x - gray) * u(0.85, 1.15)                              # mil
    x = x + tf.random.normal(tf.shape(x)) * u(0.0, 10.0) * coin(0.5)   # gau
    sigma = tf.random.uniform([], 0.6, 1.8)
    mb = coin(0.3)
    x = mb * gaussian_blur(x, sigma) + (1.0 - mb) * x                  # blu
    return tf.clip_by_value(x, 0.0, 255.0), y

Severity + "Uncertain" rule in Dart (reads severity_config.json )
const _sev = ['Mild', 'Moderate', 'Severe'];
String? severity(String label, double conf, Map cfg) {
  if (conf < cfg['uncertain_below']) return 'Uncertain';  // ask to retake photo
  if (label == 'Healthy') return null;                    // no severity for hea
  var s = conf < cfg['mild_max'] ? 0 : (conf < cfg['moderate_max'] ? 1 : 2);
  final floor = cfg['min_severity_by_class'][label];      // e.g. Newcastle is n
  if (floor != null && s < _sev.indexOf(floor)) s = _sev.indexOf(floor);
  return _sev[s];
}
